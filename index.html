Best folder setup
  • One subtitle file and one media file per clip
  • Matching names like clip_01.srt and clip_01.mov
  • Visible numbering so the merge order is obvious
If the scan stops
  • Look for missing media or subtitle counterparts
  • Rename files so each pair shares the same base name
  • Drop the folder that directly contains the files, not a higher parent folder

Use one folder for one export. Match each subtitle to a media file with the same base name, such as video_01.srt + video_01.mov or audio_01.srt + audio_01.mp3.

Keep a visible number in each filename. The app merges pairs in numeric order and shifts each subtitle by the previous clip's duration.

Extra unrelated files are ignored. Files inside nested subfolders are skipped so you can drop a real-world folder without cleaning it first.
